세션 통신 유형

세션수 기준
판단 기준

세션을 상대 IP의 주소 유형으로 분류합니다. 유니캐스트만 호스트 간 실제 데이터 통신이고, 멀티·브로드캐스트는 이름 해석·장치 탐색용 제어 트래픽입니다.

유니캐스트특정 호스트와 1:1 통신 — 클라이언트 ↔ 서버
멀티캐스트그룹 주소(224–239.x)로 다수에 전송 — LLMNR·mDNS 이름 해석
브로드캐스트서브넷 전체에 전송(말단 .255) — NetBIOS·DHCP 등 탐색

상위 로컬 IP

로컬 = 사설 IP · IPv4 10.x · 172.16–31.x · 192.168.x · 127.x, IPv6 링크로컬 fe80::/10 · ULA fc00::/7 · ::1

상위 리모트 IP

리모트 = 공인 IP · 사설 대역이 아닌 외부 주소.
세션수는 유니캐스트(1:1 실제 통신)만 집계 — 멀티캐스트·브로드캐스트 제외

프로토콜 분포

데이터셋 수집 · 추출 방법

COLLECTION
  • 수집 방식  15개 앱별 활동 스크립트 실행, VPN ON/OFF 각 별도 수집 — 수집 대상 앱만 격리 실행 후 Local IP 필터링 pcap 저장
  • 수집 환경  연구 목적 통제 환경 (캐나다 UNB) — Wireshark/tcpdump 기반 캡처, VPN 트래픽은 TUN 가상 인터페이스에서 수집
  • 폴더 명명: {group}_{service}_{app}
    예) VPN_Streaming_Netflix, nonVPN_Chat_Skype
TOOLS
Wireshark 패킷 캡처
tcpdump 패킷 캡처
ISCX-FlowMeter 특징 추출
OpenVPN VPN 클라이언트
PIPELINE
원본 pcap → tshark 1-pass → 통계 집계 → data.json → 대시보드
  • 폴더(클래스) 단위 통계 집계 후 data.json 단일 파일로 저장
  • 폴더 단위 멀티프로세싱으로 병렬 처리
  • 패킷 크기 — 스트리밍 누적 히스토그램으로 처리 (대용량 pcap 메모리 안정화)
